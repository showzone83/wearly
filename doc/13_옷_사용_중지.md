# 13. 사용하지 않는 옷 · 완전 삭제

> 백엔드(`backend/`)와 앱(`mobile/`)이 함께 따르는 계약이다. 2026-10-17 결정.

## 1. 배경

지금 옷 상세에는 "삭제"만 있어서, 더 이상 입지 않는 옷을 지우면 그 옷이 들어간 착용 기록·코디의 흔적도 사라진다. 버리거나 기부한 옷도 "이런 옷을 가지고 있었고 이렇게 입었다"는 기록은 남기고 싶다.

| 동작 | 뜻 | 되돌리기 | 기록 |
|---|---|---|---|
| **사용하지 않는 옷으로** (사용 중지) | 옷장에서 빼되 데이터는 남긴다. 이유(안 입음·버림·기부·판매·기타)와 날짜를 남긴다 | "다시 사용하기"로 되돌린다 | 착용 기록·코디·통계 이력에 그대로 남는다 |
| **완전 삭제** | 아이템과 사진을 지운다 | 되돌릴 수 없다 | 이 옷이 들어간 코디·착용 기록에서는 빠진다(지금 동작과 같음) |

## 2. 데이터

### 아이템 컬럼 (`tb_wardrobe_item`, 새 Flyway 마이그레이션)

| 컬럼 | 형식 | 설명 |
|---|---|---|
| `retired_at` | `TIMESTAMPTZ NULL` | 사용 중지 시각. NULL이면 사용 중 |
| `retire_reason` | `VARCHAR(30) NULL` | `RETIRE_REASON` 코드 |
| `retire_memo` | `VARCHAR(200) NULL` | 메모 (예: "아름다운가게 기부") |

- 사용 중지는 보유 상태(`status`: 보유·세탁·수선)와 별개다. 사용 중지를 풀면 원래 `status`로 돌아온다.
- 인덱스: 목록 조회가 사용 중인 옷만 보는 경우가 많으므로 `(user_id) WHERE retired_at IS NULL` 부분 인덱스.

### 코드 그룹 `RETIRE_REASON` (06 문서 코드 테이블에 추가)

| 코드 | 라벨 |
|---|---|
| `NOT_WORN` | 안 입어요 |
| `DISCARDED` | 버렸어요 |
| `DONATED` | 기부했어요 |
| `SOLD` | 팔았어요 |
| `ETC` | 기타 |

관리자 사이트 코드 관리에서 다른 그룹처럼 추가·수정할 수 있다(attrs 없음).

## 3. API (`/api/v1/wardrobe`)

| 메서드 | 경로 | 요청 | 응답 |
|---|---|---|---|
| POST | `/items/{id}/retire` | `{ reason, memo? }` | 200 아이템. 이미 사용 중지면 이유·메모만 바꾼다(시각은 그대로) |
| POST | `/items/{id}/restore` | — | 200 아이템. 사용 중이면 그대로 200 |
| DELETE | `/items/{id}` | — | 204. **완전 삭제** (지금과 같음) |
| GET | `/items?retired=` | `false`(기본) · `true` · `all` | 목록 |

- 아이템 응답에 `retiredAt: string|null`, `retireReason: string|null`, `retireMemo: string|null`을 더한다.
- `reason`은 활성 `RETIRE_REASON` 코드, `memo`는 200자 이하. 틀리면 400 `VALIDATION_FAILED`.
- 사용 중지된 옷은 PATCH로 속성을 고칠 수 있다(기록 정리용). bulk 등록은 사용 중 상태로만 만든다.
- **통계** `/wardrobe/stats`: 지금 숫자(`total`·`byCategory`·…·`utilization30d`·`sleeping`)는 **사용 중인 옷만** 센다. 새 필드 `retired: number`(사용 중지한 옷 수)와 `retiredByReason: { reason, count }[]`를 더한다.
- **AI 코디 추천·사진 분석 한도** 등 추천 후보에서는 사용 중지한 옷을 뺀다. 고정·중심 아이템으로 사용 중지한 옷을 주면 400.
- **코드 삭제 가드**(`CODE_IN_USE`)는 사용 중지한 옷도 센다(데이터가 남아 있으므로).
- 관리자 회원 목록의 `itemCount`는 사용 중인 옷 수(사용 중지 수는 따로 `retiredItemCount`).

## 4. 앱

### 옷 상세
- 상단에 사용 중지 상태면 배너: "사용하지 않는 옷 · 기부했어요 · 2026.10.17" + 메모 + **"다시 사용하기"** 버튼.
- 아래 "관리" 영역:
  - **사용하지 않는 옷으로** 스위치(또는 버튼) → 시트: 이유 선택(칩, `RETIRE_REASON` 코드) + 메모(선택) + "옮기기". 안내: "옷장과 추천에서는 빠지고, 착용 기록은 그대로 남아요."
  - **완전 삭제** (빨간 글자 버튼) → 확인 대화상자: "사진과 정보가 지워지고 되돌릴 수 없어요. 이 옷이 들어간 코디·기록에서도 빠져요. 버리거나 기부한 옷이라면 '사용하지 않는 옷'으로 옮기는 걸 권해요." [취소] [완전 삭제]
- 사용 중지한 옷은 수정은 되지만 "오늘 코디에 넣기" 같은 추천 동작은 숨긴다.

### 내 옷장
- 기본 목록은 사용 중인 옷만. 필터 줄 끝에 "사용 안 함 (N)" 칩 → 사용 중지한 옷 목록(흐리게, 이유 배지).
- 통계 문구(총 N벌)는 사용 중인 옷 기준. 사용 중지가 있으면 "사용 안 함 N벌" 작게.

### 추천·기록
- 규칙 엔진과 AI 코디 요청에서 사용 중지한 옷은 후보에서 뺀다(서버도 뺀다).
- 착용 기록·캘린더·진단처럼 과거를 보여 주는 화면은 사용 중지한 옷도 그대로 보여 준다(옷 이름 옆에 "사용 안 함" 작은 표시).
- 완전 삭제는 지금처럼 로컬 코디·기록에서 그 옷을 뺀다.
