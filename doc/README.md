# Wearly 문서

> 작성일: 2026-10-15

웨어리(Wearly)는 비즈니스 캐주얼로 출근하는 직장인을 위한 데일리 스타일리스트 앱이다. 새 옷을 사기보다 이미 가진 옷으로 출근 코디 3안을 추천하고, 착용 기록을 바탕으로 코디를 진단·처방한다. 이 폴더는 [기획서 v1.1](../Wearly_서비스_기획서_v1.1.pptx)을 분석하고, 기술 방향을 정하고, [목업 앱](../mobile/)을 만든 과정을 정리한 것이다.

## 빠른 실행

처음 한 번만 의존성을 설치한다.

```bash
cd /Users/showzone/Workspace/wearly/mobile
```

```bash
npm install
```

그다음부터는 mobile 폴더에서 이것만 실행한다. 테스트

```bash
npx expo start
```

- 휴대폰: Expo Go 앱을 설치하고, Mac과 같은 Wi-Fi에서 터미널의 QR 코드를 스캔한다.
- 브라우저: 같은 터미널에서 `w` 키를 누른다.
- 종료: `Ctrl+C`

자세한 내용과 문제 해결은 [04_목업_앱.md](04_목업_앱.md) 2장에 있다.
